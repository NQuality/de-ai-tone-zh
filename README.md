# de-ai-tone-zh

中文写作去 AI 味的自检 skill。文章写完后跑一遍，对照负面清单逐条扫，命中就改——只做精准微调，不重写。

适合谁：写公众号、博客、小红书、报告、任何中文长短文的人，以及帮别人改稿时想有个统一口径的编辑/Agent。

## 它解决什么

AI 写中文有一套稳定指纹：翻案腔、"说白了"起手、翻译腔长定语、破折号满天飞、朗诵体对仗、结尾口号加引流、单行金句收尾……读起来"很 AI"。这个 skill 把去味规则整理成 12 条可勾选的清单，并附上"哪些必须保住"的对照，避免把好句子、正常排版、信息密度一起砍掉。

核心立场：**去 AI 味是精准微调，不是重写。** 漏改一处比错砍一处代价小。

## 怎么用

装成 Agent skill 后，写完文章说一句"去 AI 味"即可。它会：

1. 有你的历史文章就先读，按你的语感来；没有就用通用口径。
2. 对照 12 条扫正文，逐条判断是否命中。
3. 每条命中先过"精准微调两栏"，落在"必须保"栏的放过。
4. 强信号单次就改，弱信号同段叠加才动。
5. 改完走验收清单，确认信息守恒、结构没动。

手动用也可以：直接读 SKILL.md，把 12 条当 checklist 逐条对照。

## 12 条一览

1. 翻案腔　2. 提示语冒号　3. 起手式　4. 翻译腔　5. 顿号罗列过密
6. 破折号超量　7. 朗诵对仗 + 造概念引号　8. 押韵口号 + 引流句
9. 单行收尾金句 / 碎句排比　10. 故作深沉格言　11. 无的放矢反驳　12. 装饰性加粗 / 标签列表

详见 [规则详解](./references/rules-detail.md)。
